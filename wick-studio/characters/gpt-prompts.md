# Weekly Wick — ChatGPT 이미지 프롬프트

명재가 ChatGPT(이미지 생성)에 그대로 붙여넣어 쓰는 프롬프트입니다. 안마다 2~3장씩 뽑고, 마음에 드는 것을 이 대화에 올리거나 Drive `wick/assets/concepts/`에 넣어주세요.

**공통 조건(모든 프롬프트에 포함되어 있음)**: 정면, 전신, 단색 배경, 글자 없음. 리그 제작을 위해 눈·입·팔·불꽃이 서로 겹치지 않고 또렷하게 분리된 형태로 요청합니다. 선택한 그림은 클로드코드가 SVG 파츠로 다시 그려 움직이게 만듭니다.
